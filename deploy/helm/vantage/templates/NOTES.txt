Point a router's BMP configuration at:

  kubectl -n {{ .Release.Namespace }} get svc {{ include "vantage.fullname" . }}-bmp \
    -o jsonpath='{.status.loadBalancer.ingress[0].ip}'

  port {{ .Values.collector.bmpPort }}

Read an API token:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "vantage.fullname" . }}-api \
    -o jsonpath='{.data.{{ (first .Values.api.tokens).name }}}' | base64 -d

Query it:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "vantage.fullname" . }}-api {{ .Values.api.port }}:{{ .Values.api.port }}
  curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:{{ .Values.api.port }}/v1/routers
