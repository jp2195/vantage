# vantage Individual Contributor License Agreement

**Draft — needs a lawyer's eye before the repository goes public.** It is
adapted from the Apache Software Foundation's Individual CLA v2.0, which is
the usual starting point and is itself widely reused. It has not been
reviewed by counsel. Do not rely on it as-is for anything that matters,
because this is the document that makes dual licensing possible and a defect
in it is only discovered when it is too late to fix.

## Why this exists

vantage is licensed to the public under the **GNU General Public License,
version 3** (see `LICENSE`). Copyleft means a company cannot take this code
into a proprietary product without releasing their own work under the same
terms.

Some organizations cannot accept those terms and would rather pay for a
license that does not carry them. Offering one is only possible if the
project holds the rights to *all* of the code it is offering — including
yours. That is what this agreement provides, and it is the only reason it
exists.

**You keep your copyright.** This is a license grant, not an assignment.
You may use, publish and relicense your own contribution however you like,
exactly as if you had never signed it.

## How to sign

Open a pull request. A bot will comment asking every author who has not
signed yet to reply with exactly:

```
I have read CLA.md and I agree to it.
```

Post that reply from your own GitHub account. It is recorded, with a link to
your comment, its id and a SHA-256 hash of its text, on this repository's
`cla-signatures` branch. You only need to
do it once, and it covers every contribution you ever make.

Every author of a pull request signs, not only the person who opened it.
That includes anyone credited in a `Co-authored-by:` line. A commit whose
email address does not match a GitHub account cannot be signed for, so the
bot will ask you to fix the address.

If this agreement's terms (the section headed "The agreement") ever change,
the bot will ask everyone to sign again, because nobody has agreed to the
new text yet. Changes to the rest of this file do not.

Contributing on behalf of a company, or on company time with company
equipment, needs a Corporate CLA signed by someone authorized to bind the
organization. Open an issue and we will sort it out.
